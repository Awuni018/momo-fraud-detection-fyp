# Mobile Money Fraud Detection in Ghana (FYP)

Final Year Project, BSc. Computer Science and Engineering
University of Mines and Technology (UMaT), Tarkwa, Ghana

## About

This project tests how well mobile money fraud detection models handle fraud they have not seen before. We extend the PaySim simulator with Ghana-relevant fraud scenarios, compare a rule-based baseline, Logistic Regression and Random Forest, and build a dataset of Ghanaian scam messages.
